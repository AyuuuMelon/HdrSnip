# 微光 HDR 截图 · HdrSnip

一个轻量的 Windows 截图工具，支持 HDR 截图、快捷键框选和基础标注。关闭设置窗口后驻留系统托盘。

## 下载与使用

从 [Releases](https://github.com/AyuuuMelon/HdrSnip/releases/latest) 下载 Windows x64 便携版，解压到有写入权限的文件夹，运行 `HdrSnip.exe`。无需安装或管理员权限。

1. 默认快捷键为 **Ctrl + Shift + S**，可在设置中修改。
2. 将鼠标移到目标屏幕，按快捷键并拖动框选。
3. 松开后可继续调整范围、添加标注，再选择复制或保存。
4. 双击右下角托盘图标打开设置，右键菜单可退出程序。

## 功能

- HDR 屏幕保存 **JXR + PNG**，普通屏幕保存 PNG。
- 选区支持移动、四边和四角调整、方向键微调。
- 方框、椭圆、箭头、画笔、文字和马赛克。
- 六种标注颜色、三种粗细、撤销和重做。
- 自定义全局快捷键与保存目录。
- 托盘后台运行，支持静默启动。

| 操作 | 快捷键 |
| --- | --- |
| 复制并关闭 | Enter / Ctrl+C |
| 保存并复制 | Ctrl+S |
| 取消 | Esc / 鼠标右键 |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y |
| 选择整屏 | Ctrl+A |
| 移动选区 | 方向键；按住 Shift 每次移动 10 像素 |
| 切换工具 | V 选区、R 方框、O 椭圆、A 箭头、P 画笔、T 文字、M 马赛克 |

文字工具中，Enter 确认文字，Esc 取消本次输入。

## 保存与 HDR

默认保存到 Windows“图片”文件夹下的 `HdrSnip`，可在设置中修改。

- **JXR** 保留 HDR 数据，需要支持 HDR 的看图软件。
- **PNG 和剪贴板**是转换后的 SDR 图像，适合粘贴、分享。
- 标注和马赛克会写入保存的图像，不会另外保存未打码的原图。
- 仅“复制”不会生成截图文件；需要留存时使用“保存”。

## 开机静默启动

给 `HdrSnip.exe` 创建快捷方式，在快捷方式“目标”末尾添加一个空格和 `--background`。按 Win+R，输入 `shell:startup`，将快捷方式放入打开的文件夹。

登录后只显示托盘图标，不弹设置窗口或启动通知。移除该快捷方式即可关闭自启动；移动程序文件夹后需更新快捷方式。

## 运行要求与限制

支持 Windows 10 / 11 64 位系统；HDR 截图需要支持 HDR 的显示器，并在 Windows 设置中开启 HDR。

目前仅支持单个屏幕内框选，不支持跨屏拼接；截图不包含鼠标指针。独占全屏、受保护视频或部分远程桌面可能无法正常捕获，游戏可尝试无边框窗口模式。SDR 图像无法完整呈现 HDR 的亮度和色域。

截图保存在本地，程序不联网。快捷键被其他软件占用时，可从托盘打开设置更换组合。

## 从源码构建

安装 Visual Studio 2022 的 C++ 桌面开发组件、Windows SDK 和 CMake，然后在项目目录运行 `build.ps1`。生成文件位于 `build/Release/HdrSnip.exe`。

开发测试可通过 CMake 选项 `-DHDRSNIP_BUILD_TESTS=ON` 启用；普通构建不包含诊断命令。
